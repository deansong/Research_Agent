WRITING THE PAPER -- an ACL-style paper from this run, and only this run.

FORMAT. LaTeX in the official ACL style, in {paper_dir}:
  main.tex        \documentclass[11pt]{article} \usepackage[final]{acl}
                  (use [review] only if the person asked for an anonymous
                  submission). \input each appendix file after the references.
  acl.sty, acl_natbib.bst
                  fetch both from
                  https://raw.githubusercontent.com/acl-org/acl-style-files/master/latex/acl.sty
                  https://raw.githubusercontent.com/acl-org/acl-style-files/master/latex/acl_natbib.bst
                  If that fails (no network), use \documentclass[11pt,twocolumn]{article}
                  instead, and say so in a comment at the top of main.tex and
                  in your report.
  references.bib  ONLY papers you confirmed exist: the research rounds listed
                  below, or a lookup with {tools} paper <arxiv id> / cites.
                  Never write a citation from memory.
  figures/        made from the result files (matplotlib, if installed);
                  the script that makes them saved beside them.
  tables/         generated by a script from the result files, never retyped;
                  the script saved too, so the tables can be regenerated.
  appendix/       one .tex file per appendix section.
  paper.md        the same paper as Markdown, for reading without LaTeX.
  main.pdf        only if `tectonic` or `pdflatex` + `bibtex` is installed:
                  compile it (run bibtex, and pdflatex twice). Otherwise
                  leave the folder ready to upload to Overleaf and say so in a
                  README.md there.

THE BODY -- at most 8 pages (a long paper) or 4 (a short one):
  Title, Abstract (one paragraph: question, method, the headline result)
  1 Introduction     the question, why it matters, what you found, contributions
  2 Related Work     only cited, confirmed papers
  3 Method           what was done, precisely enough to judge it
  4 Experimental Setup   data, models, baselines, metrics, protocol
  5 Results          the main tables and figures, with the numbers that
                     settle the question
  6 Analysis         what the results mean; the ablations and checks that
                     support or limit that reading
  Limitations        REQUIRED by ACL: what this run cannot show, and why
  Ethics Statement   data, people, misuse -- short, specific
  References

THE APPENDICES -- no page limit. Everything important that the body has no
room for goes here, and the body points to it ("full results in Appendix B"),
so every claim in the body is backed by a complete table:
  A  Full results      every configuration, seed, model and split, as tables
                       generated from the result files -- including runs that
                       failed or were dropped, and why
  B  Experimental settings   datasets and versions, preprocessing, prompts and
                       templates, hyperparameters and how they were chosen,
                       model checkpoints and versions, hardware, compute time
                       and cost
  C  Reproducibility   exact commands, environment and package versions,
                       random seeds, the paths of the result files and logs
  D  Additional analyses   ablations, sensitivity checks, error analysis with
                       examples, extra figures
  E  Run record        the approved plan, deviations from it, each step's
                       final report (condensed), and the validator's findings
                       that changed the experiment
  Anything else a step report or the orchestrator flags as important.

HONESTY. Report what was measured. A negative or null result is a result:
say "the hypothesis is not supported" plainly, with the numbers. Every number
in the paper must come from a file under the results; never round a number
into a different conclusion, and never claim more than was run.
